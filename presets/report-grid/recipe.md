report-grid: tidy report style that follows the Korean corporate report convention (title / governing message / body). For business, internal reports, and proposals.

## Layout principles
- Build every body slide in three tiers: title (the claim), governing message (one muted sentence), body.
- On the 12-column grid, lay out asymmetrically as 7+5 or 8+4. Evidence on the left, the key number or a small chart on the right.
- Tables use horizontal rules only. No vertical lines and no filled header row. Make the header row bold and right-align number columns.
- Use the accent color in only one place per slide: one of the key number, the highlighted bar in a chart, or the highlighted row in a table.

## Slide types that fit this style
Big number + caption, comparison table, bar/line chart (one highlight), 2×2, step process (only when there is a real order)

## Don't
- Three-card grids (L1), left stripes on cards (L5), a rule under the title (L6)
- Icon decoration
- Writing the governing message at the same length on every slide (W9)
